# hyw

Phigros 谱面预览与游玩 —— 在浏览器里导入 `.pez` 谱面包，让谱面自己跑一遍看效果，或者亲自上手打。

基于 Vite + TypeScript + Pixi.js，自带一套 RPE 谱面解析器和判定层。

## 功能

- **观赏模式**：只按谱面播放，不做判定，用来检查谱面写出来的观感。
- **游玩模式**：带判定和计分，结算给出准确率与评级。
- 支持 RPE 扩展事件：判定线换成图片、染色、拉伸缩放，以及在判定线上显示文字。
- 按谱面数据还原音符可见性（上隐 / 全隐）与假音符，和 RPE 的表现一致。
- 支持拖拽导入 `.pez`，也可以把谱面放进项目的 `charts/` 目录常驻谱面库。
- 可微调判定偏移，用来对齐不同设备的音频延迟。

## 环境要求

Node.js `^20.19.0 || >=22.12.0`（下限由 Vite 8 决定）。

## 快速开始

```bash
npm install
npm run dev
```

然后打开终端里给出的地址。

### 脚本

| 命令 | 作用 |
| --- | --- |
| `npm run dev` | 启动开发服务器 |
| `npm run build` | 类型检查通过后打包到 `dist/` |
| `npm run preview` | 预览打包产物 |
| `npm run check` | 只做类型检查（`tsc --noEmit`） |
| `npm run check:judgment` | 运行判定层自检脚本 |
| `npm run check:text` | 运行文字事件自检脚本（显示时长、清除、打字机） |

## 操作

- `空格`：开始 / 暂停
- `D` `F` `J` `K`：也可以当点按用
- 游玩界面下方可以拖动进度条、切换观赏 / 游玩模式、微调判定偏移

## 导入谱面

两种方式：

1. 在「导入谱面」页把 `.pez` 拖进拖放区，或点「选择文件」。
2. 把 `.pez` 放进项目根目录的 `charts/`，刷新页面即会出现在谱面库里。

第二种方式走的是构建期的 `import.meta.glob`（见 `src/ui/chartLibrary.ts`），
所以放进去之后要刷新页面，不需要维护任何清单文件。

`.pez` 本质是个 ZIP 包，内含一份 RPE 谱面 JSON、音频、曲绘和 `info.txt` 元数据。

## 项目结构

```
src/
  chart/     RPE 谱面解析：.pez 解包、事件解析、缓动函数
  game/      输入跟踪、判定规则、一次游玩的状态机
  render/    Pixi.js 谱面渲染
  audio/     基于 Web Audio 的歌曲时钟
  ui/        谱面库与界面切换
tools/       判定层自检脚本
```

判定参数全部集中在 `src/game/judgment.ts`，每一条都注明了假设，想调手感改这一个文件就可以。
改完记得跑 `npm run check:judgment`——它会合成一份 BPM 60 的谱面，断言各评级边界、
Drag / Flick / 长按的行为以及计分公式。

判定线的长度和粗细由 `src/chart/textures.ts` 的 `DEFAULT_LINE_UNITS` 决定（谱面包里没有
`line.png`，用的是兜底值），粘贴面的扩展 `scaleX`/`scaleY` 是**直接倍数**：1 = 贴图自然大小，
负数是绕 anchor 镜像。

## 渲染约定（和 RPE 对齐的几处）

- **叠放顺序只看 `zOrder`**：所有判定线在同一个容器里按 `zOrder` 从小到大画，音符和文字画在线之上。
  `isCover` 不参与分层——它只是「这条线是遮罩」的标记，实测谱面里它一律是 1（编辑器默认值），
  拿它当「画在最上面」会让铺满屏幕的幕布线把字幕和音符全盖住。
- **`scaleX` 是长度倍数、`scaleY` 是厚度倍数**。拿默认线当「全屏黑幕 / 白闪」用时靠的是**纵向**：
  作者的配方是 `scaleX=1` + `scaleY=200~300`（谱面里确实这样，因为 `line.png` 本身就有约 3 屏长，
  横向再放大在画面上看不出来）。因此渲染时两条轴分别限制在「3 屏」以内——按轴限制而不是等比，
  铺满屏幕的细长条才不会被压成一根细棍。
- **判定线的透明度只管线和线上的文字**，不管音符。游戏里「判定线消失」是常用手法。
- **音符可见性**由三样东西决定：`visibleTime`（判定前多少秒内可见；负数 = 作者故意让它不出现）、
  音符自身的 `alpha`（0 = 隐藏）、以及 `isFake`（假音符：外观和真音符一样，到判定线就消失、不参与判定和计分）。
- **音符外观**照 PhiEdit 自带的音符贴图还原：尺寸 200×30 RPE 单位（拖曳 18），配色是饱和的
  青 `#0AC3FF` / 黄 `#F0ED69` / 粉 `#FE4365`（长按浅青 `#99E6FC`）。点按和拖曳是「白色外框 + 中间色带」，
  滑动多一个白色尖角；长按条的身体是**靠头端实、远端虚的透明度渐变**，不是一块均匀的半透明板。
- 带文字事件的判定线**只画文字**，不画自己的贴图。

排查谱面时可以打开控制台用这几个调试接口：

```js
hyw.showAllNotes(true)        // 把故意隐藏的音符（visibleTime<0、alpha=0）也画出来
hyw.renderAt(70).noteSkips    // 当前帧音符没画出来的原因分类：alpha / resolved / notYetVisible / fake / past / culled
hyw.lineInfo(0)               // 第 0 条判定线当前的 scaleX/scaleY、alpha、屏幕尺寸、贴图名
```
